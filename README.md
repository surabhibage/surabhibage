# Relevant Projects: 
## [💡Energy Consumption Predictor](https://github.com/surabhibage/Energy-Consumption-Predictor)
• Developed from scratch a mathematical and machine learning–based linear predictor of household energy usage, integrating
linear least squares and multivariate regression to quantify key consumption drivers.<br/>
• Analyzed the U.S. Energy Information Administration’s 2020 dataset, identifying relationships between geography, housing
characteristics, and appliance usage to uncover variables most influencing household energy demand.<br/>
• Applied classification and dimension-reduction techniques to refine predictive accuracy and improve interpretability of model
results.<br/>

## [🏞️ Full Stack Photo Album Application](https://github.com/surabhibage/Photo-Album-App/tree/master)
• Engineered a full-stack photo album application from scratch with a Java back end and Swing UI, leveraging OOP design
patterns (MVC, strategy, inheritance, polymorphism) to create a modular and extensible architecture.<br/>
• Implemented MVC architecture and the strategy pattern to separate business logic from presentation, simplifying feature
expansion and maintenance.<br/>
• Enabled dynamic user functionality, including navigation, add/delete operations, and multi-criteria sorting (name, date, size) via
iterators, verified through UML class diagrams and testing workflows.<br/>

## [📈 Finance Data Analysis](https://github.com/sjsu-cs131-f25/team3-finance-analysis)
• Prepared raw CSV data for analysis using awk/sed to clean formats, remove outliers, and validate quality, enabling reliable
financial insights.<br/>
• Built a Spark + Parquet pipeline to aggregate income, expenses, and savings by region, gender, and education to uncover
behavioral patterns to perform data analytics.<br/>
• Deployed on GCP Dataproc Serverless with parallel execution to transform and deliver structured insights back to Cloud Storage,
validated via Spark UI.<br/>
